## 产品逻辑（决定 UI 形态的三件事）

1. **源是可增删的一等公民** —— 不是隐藏的高级设置，而是「我的」里一个有健康状态、延迟、优先级的列表。这决定了要有独立的「播放源管理」页。
2. **重渲染发生在应用层** —— 用户看到的永远是影枢的界面与播放器，不是网页套壳。所以播放器页要有「影枢渲染层」这样的状态提示，让用户确信画面是被接管的。
3. **多源并存 ⇒ 同片跨源** —— 搜索结果按内容合并（一部片一条结果，展开看到各源可播性），详情页与播放器里切源是主交互，且**切源不丢进度**。

## 设计系统

**风格**：OLED 深黑 + 影院感（`dark-mode-oled`），内容优先，无浅色模式。

**色彩令牌**

| 角色 | 值 | 用途 |
|---|---|---|
| `--bg` | `#000000` | OLED 纯黑底 |
| `--surface` / `--surface-2` | `#0C0C0D` / `#16161A` | 卡片 / 次级面 |
| `--play-500` | `#E11D48` | 播放、主 CTA、选中态 |
| `--src-500` | `#22D3EE` | **源与渲染层专属色**（延迟、源徽标、渲染标签） |
| `--ok-500` / `--warn-500` / `--err-500` | `#34D399` / `#FBBF24` / `#F87171` | 源健康状态三态 |
| `--gold` | `#F5C451` | 评分 |

用**青色专属于「源」**是一条刻意的约束：用户在任何一个界面看到青色，就知道那是在讲播放源的事，不必重新理解配色。

**字体**：Inter（含中文回退 HarmonyOS Sans SC / PingFang SC）。

**栅格**：4/8dp 节奏；圆角 8/12/16/20/999。

## 规范落实情况

- 图标全部为内联 SVG 线性图标，无 emoji 充当结构图标
- 触控目标 ≥44dp（源切换 FAB 46×52、底部按钮 46 高、集数格 38 高但外扩热区）
- 深色模式正文对比度 ≥4.5:1（正文 `#F8FAFC` 于 `#000` 约 19:1；次级 `#94A3B8` 约 7.4:1）
- 状态不只用颜色表达：异常源同时有「连接失败」文字徽标 + 错误标签，非仅靠红点
- 无位移动效：按压态只用颜色/透明度，不改布局边界
